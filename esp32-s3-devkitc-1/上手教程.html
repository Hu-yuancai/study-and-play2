① 这是什么，我要做什么

你买的这堆零件，最终会拼成一台小型掌上游戏机。整个过程就三件事：

1. 接线
把屏幕、键盘、蜂鸣器，用面包板和杜邦线连到 ESP32 主板的正确引脚上。
2. 烧录
用数据线把电脑里写好的程序传进 ESP32 芯片里（叫"烧录"或"上传"）。
3. 开玩
通电，屏幕亮起菜单，用键盘选游戏。
说明程序代码已经全部写好了，你不需要会编程。你要做的是：装好工具 → 照着接线表把线插对 → 点一个"上传"按钮。本教程假设你完全没碰过这些。
好消息这个项目在电脑模拟器（Wokwi）里已经验证过，接线关系是确定的。你只要照抄下面的接线表就行。

认识 ESP32 主板

主板两侧各有一排金属引脚，每个引脚旁边印着小字编号，比如 1 4 GND 3V3。接线全靠认这些编号。

  • 3V3 = 3.3V 正电源（给模块供电的"火线"）
  • GND = 地线（电源的"零线"，板上有好几个，任选）
  • 数字 = GPIO 信号脚，比如 4 就是 GPIO4，编号必须对上
  • 板子一端有 两个 USB-C 口。靠近边角、标着 UART / COM 的那个用来烧录最稳妥（两个口一般都能用，不行就换另一个）。

③ 安装软件（一次性，约 20 分钟）

程序是用 PlatformIO 写的。它是 VS Code 编辑器里的一个插件。装好后，烧录就是点一个按钮的事。

1

装 VS Code

打开浏览器搜索 VS Code，进官网 code.visualstudio.com，下载 Windows 版，一路"下一步"装完。这是个免费的代码编辑器。
2

装 PlatformIO 插件

打开 VS Code → 点左边竖排图标里那个四个方块（扩展 Extensions）→ 搜索框输入 PlatformIO IDE → 点第一个结果的 Install。
耐心等装完它会在后台下载一堆编译工具，第一次可能要 5–15 分钟，右下角有进度。装好后会提示重启 VS Code，点重启。
3

装 USB 驱动（让电脑认识主板）

ESP32-S3 用 USB 直连一般免驱。先跳过这步，等接好线插上电脑后，如果在设备里看不到串口，再回来装。常见驱动是 CH343 / CP210x，搜索对应名字下载安装即可。
4

用 VS Code 打开本项目

VS Code 顶部菜单 File → Open Folder，选中这个文件夹： 
260523-190907-esp32-s3-devkitc-1
打开后，左下角蓝色状态栏会出现一排小图标（✓ 对勾、→ 箭头、🔌 插头、🗑 垃圾桶）。这就是 PlatformIO 的按钮，烧录全靠它们。
说明项目里的 platformio.ini 已经配好了用哪块板子、需要哪些库。第一次编译时 PlatformIO 会自动联网下载 U8g2、Adafruit GFX、Adafruit ILI9341 三个库，保持网络畅通即可，无需手动装。

④ 接线（最关键的一步，慢慢来）

下面每张表的右列 = ESP32 主板上的引脚编号，左列 = 模块上的引脚名。一根线连两端，对着编号插就行。建议每接完一个模块，回头核对一遍再接下一个。

先断电接线时 USB 先不要插电脑。全部接完、核对无误后再通电。带电插拔容易烧模块。

总电源怎么走

所有模块都要"吃电"（VCC）和"接地"（GND）。最省事的做法是用面包板的电源轨：

  1. 从 ESP32 的 3V3 引一根线到面包板 红色"+"轨。
  2. 从 ESP32 的 GND 引一根线到面包板 蓝色"−"轨。
  3. 之后每个模块的 VCC 都插红轨，GND 都插蓝轨。这样就不用从主板引很多根电源线。
重要模块电源一律接 3V3，不要接 5V。ESP32-S3 的 GPIO 是 3.3V 的，屏幕也按 3.3V 用，接 5V 可能损坏。

🟦 模块 1：ILI9341 彩色主屏（SPI，14脚模块）

这块屏脚最多。它有 14 个脚，但带 SD 卡的 4 个脚（SD_CS/SD_MOSI/SD_SCK/SD_MISO）不用接，只接下面 9 个。

地址程序按 I2C 地址 0x3C 写的，市面 0.96 寸 OLED 基本都是这个地址，直接用。

🟩 模块 3：4×4 矩阵键盘（8 根线，无正负之分）

键盘有 8 个脚，分成"行(Row) 4 个"和"列(Column) 4 个"。它不需要接电源，8 个脚全是信号线。把排线/接口面对自己，从左到右一般就是 行1 行2 行3 行4 列1 列2 列3 列4。

行2 / R2GPIO 2
行3 / R3GPIO 3
行4 / R4GPIO 5
列1 / C1GPIO 14
列2 / C2GPIO 15
列3 / C3GPIO 16
列4 / C4（最右）GPIO 17
接反了也不怕如果接好后发现"按 1 出来的是 3"之类按键错位，多半是行/列插的顺序反了。先把 4 根行线整体和 4 根列线整体对调试试，或在下一节用串口看实际键值再微调。不会烧坏东西。

🔊 模块 4：无源蜂鸣器（3 脚模块）

蜂鸣器引脚接到 ESP32类型
VCC / +3V3（红轨）电源
GND / −GND（蓝轨）地
I/O / S（信号）GPIO 18信号
关于声音这是低电平触发的无源蜂鸣器，程序里用 PWM 输出方波让它发出不同音调。如果完全不响，先确认是无源蜂鸣器、信号脚接的是 GPIO18，且 VCC 接的 3V3。

⑤ 烧录程序到主板

接线核对完毕后，把 USB 线一头插主板（标 UART/COM 的口优先），一头插电脑。主板上的电源灯应该亮起。

1

编译（Build）

在 VS Code 左下角蓝条上，点那个 ✓ 对勾 图标（PlatformIO: Build）。
第一次很慢它会先下载三个库再编译，可能要几分钟。底部终端最后显示绿色 SUCCESS 就成功了。如果是红色 FAILED，把报错文字复制下来去查（多半是网络没下全库，重点几次即可）。
2

上传（Upload）= 真正的烧录

点蓝条上的 → 右箭头 图标（PlatformIO: Upload）。它会自动编译并把程序写进芯片。终端出现 Writing... 进度条、最后 SUCCESS 即完成。
3

烧不进去？手动进下载模式

少数情况上传卡在 Connecting....。这时：按住主板上的 BOOT 键不放 → 按一下 RST/EN 键 → 松开 BOOT，让芯片进入下载模式，再点一次 → 上传。
成功标志上传成功后主板会自动重启，彩色主屏立刻亮起菜单，蜂鸣器"嘀"一声，OLED 开始眨眼。看到这些，硬件就全部打通了！

看运行日志（可选，排错神器）

点蓝条上的 🔌 插头 图标（Serial Monitor，波特率 115200）。能看到程序打印的信息，比如开机会打印 === ESP32-S3 Learning Game Machine ===。屏幕不亮但这行能出来，说明主板没问题、问题在屏幕接线。

⑥ 开始玩

开机进入彩色菜单，共 10 个功能（6 游戏 + 4 学习）：钢琴 / 飞机大战 / 扫雷 / 贪吃蛇 / 俄罗斯方块 / 2048 / 番茄计时 / 背单词 / 数学速算 / 记忆翻牌。菜单可上下滚动，用键盘 A 上、B 下 选择，0 或 # 确认进入，任何时候按 * 回主菜单。

通用规则几乎所有游戏：A/B/C/D = 上/下/左/右，0 或 # = 确认，* = 返回主菜单。每个游戏的特殊键见下面各自说明。
🎹 钢琴游戏
音符从上往下掉，到底部白色判定线时按对应轨道键（1/2/3/4 或 A/B/C/D）才得分并发声。
进入后等 3 秒自动开始。5/6 切歌（共6首），0/# 暂停。判定已放宽、音符已调慢，比之前更好上手。按住 1+2 或 3+4 触发隐藏角色动画。
✈️ 飞机大战
A/B/C/D 四方向移动，9 键或 0/# 射击（射击已修好，按了必发弹）。撞机或漏敌机扣命，3 条命用完结束。
每约 10 秒升一级，敌机变快变强。结束后 0/# 重开。
💣 扫雷
方向键 A/B/C/D 移动光标，0/# 揭开格子，9 键(C)插旗/取消旗。数字=周围雷数，揭开空白会自动展开一片。
1/2/3 切换难度（简单8×8/中等12×12/困难16×16），5 重开。踩雷即失败，揭开所有非雷格获胜。和电脑版规则一样，只是用方向键移动光标代替鼠标点击。
🐍 贪吃蛇
方向键 A/B/C/D 控制蛇头转向（不能直接掉头），吃红色果子变长 +10 分并加速。
撞墙或撞到自己身体即结束。0/# 暂停，结束后 0/# 重开。
🧱 俄罗斯方块
C/D 左右移动，A 旋转，B 软降（加速下落），9 键硬降（直接落到底）。
消除整行得分，10 行升一级、下落变快。5 暂停。顶到顶部即结束，0/# 重开。
🔢 2048
方向键 A/B/C/D 把所有数字向该方向滑动，相同数字相撞合并翻倍。
拼出 2048 获胜（可按 0/# 继续玩）。棋盘填满且无法合并即结束，0/# 重开。
🍅 番茄计时
A/B 选 25/30/45/60 分钟，0/# 开始专注倒计时。0/# 可暂停，时间到播放成功音乐。
专注期间副屏循环播放动态表情包陪伴。
📖 背单词
进入先选：1=翻卡片，2=选择题。翻卡片：主屏显英文→0/#看释义（中文在副屏）→1记得/2不记得。选择题：主屏英文+副屏4个中文选项，按 1/2/3/4 选。
内置60个常用词，主屏英文/副屏中文分工显示。
➗ 数学速算
进入先选：1=加减 / 2=乘除 / 3=混合。每轮10题，主屏显算式+4个数字选项，按 1/2/3/4 选答，结算给评级。
题目越往后越难，会出现三数连算。
🃏 记忆翻牌
4×4=16张牌=8对字母。方向键移光标，0/# 翻牌，翻开两张相同则消除、不同则盖回。全配对获胜，统计步数。
锻炼记忆力。方向键 A/B/C/D 或 2/8/4/6 都行。
⏰ 游戏限时（防沉迷）
连续玩游戏超过 10 分钟会自动弹"该休息了"并踢回主菜单。
学习模块（番茄/背单词/数学/记忆）不计入限时。这是"学习机"定位的核心机制。
👻 隐藏彩蛋：Ghost Shell
在主菜单依次按：A A B B C D C D 9 0（上上下下左右左右+9+0）。
按对后蜂鸣器"嘀嘀嘀"三声，进入一个黑底绿字的十六进制内存编辑器（可调扫雷参数等）。按 * 退出。纯属彩蛋，不影响正常游戏。

⑦ 出问题了怎么办

插上电脑，VS Code 找不到串口 / 上传报 "could not open port"
  • 换一根能传数据的 USB 线（最常见原因）。
  • 换主板上另一个 USB-C 口试试。
  • 装 USB 驱动：搜索 CH343 驱动 或 CP210x 驱动 下载安装，重插。
上传一直卡在 Connecting…… 按住 BOOT → 点一下 RST/EN → 松开 BOOT，再点上传。
彩色屏不亮 / 白屏 / 花屏
  • 白屏多半是某根 SPI 线没插好：重点查 CS(10)、DC(4)、RST(8)、MOSI(11)、SCK(12) 五根。
  • 完全不亮：先确认 VCC 接 3V3、LED 背光脚也接了 3V3、GND 接好。
  • 用串口监视器看是否打印了开机字样，判断是主板问题还是屏幕接线问题。
OLED 副屏黑屏 检查 SDA(6)、SCL(7) 有没有插反；VCC 接 3V3、GND 接好。两根信号线对调一下试试。
按键没反应 / 按键错位 键盘 8 根线里，把 4 根"行线"和 4 根"列线"整体对调试试；或确认行接 1/2/3/5、列接 14/15/16/17，顺序别乱。
蜂鸣器不响 确认是无源蜂鸣器；信号脚接 GPIO18；VCC 接 3V3。有源蜂鸣器换不出曲调，要换无源的。
钢琴游戏没声音 / 听不到曲子 这是正常机制：钢琴只有在你按中下落的音符时才发声，没有自动伴奏。音符落到底部白色判定线那一刻按对应轨道键（1/2/3/4 或 A/B/C/D）才会响并得分。判定窗口和下落速度已调宽松，对着判定线按即可。完全没声还要确认蜂鸣器本身正常（见上一条）。
飞机大战按 9 不射击 已修复。新版固件里 9 键和 0/# 都能射击，按一下发一发。如果还不行，先用键盘自检确认 9 键正常（见键盘相关条目），并确保烧的是最新固件。
编译失败 FAILED 多半是库没下全。保持联网，再点一次 Build。仍失败就把终端红色报错文字复制出来查。
