# ESP32-S3 多功能学习游戏机

基于 **ESP32-S3-DevKitC-1** 的掌上学习与娱乐一体机，集成 **7 款游戏** + **3 个学习模块**，双屏显示（彩色 TFT + OLED），矩阵键盘操控，蜂鸣器音效。支持 Wokwi 云端仿真与实物搭建。
核心代码在文件夹esp32-s3-devkict-1，项目代码主要在vscode中完成，需要安装woki和platformIO插件，开发过程适用Claude code辅助。

---

## 🎮 功能一览

### 游戏模块（7款）
- **Piano Game** — 节奏下落音游，6 首内置曲目（小星星/生日快乐/欢乐颂等），自动演奏真实旋律
- **Plane Battle** — 纵版射击，等级系统，多命制
- **Minesweeper** — 经典扫雷，自动展开，旗标标记
- **Snake** — 贪吃蛇，果实随机刷新
- **Tetris** — 俄罗斯方块，消行计分
- **2048** — 数字合并，双缓冲渲染
- **Study Buddy** — 番茄工作法计时（25/30/45/60 分钟）

### 学习模块（3款）
- **Vocabulary** — 背单词（翻卡片 + 选择题），内置词表
- **Math Drill** — 数学速算（加减乘除混合运算）
- **Memory** — 记忆翻牌（4×4 配对游戏）

### 特色功能
- **游戏时长限制** — 连续游戏 10 分钟自动弹出提醒，防沉迷
- **OLED 动态表情** — 18 种表情，钢琴模式支持组合按键触发全屏角色动画（phanion / mydei）
- **Ghost Shell 彩蛋** — Konami 码（↑↑↓↓←→←→）解锁隐藏调试终端

## 📖 使用说明

### 开机与主菜单

1. **供电**: USB-C 供电（建议 5V/1A 以上手机充电器，低压会触发 BROWNOUT 复位）
2. **开机**: 插电自动启动，彩色主菜单显示 10 个功能卡片，OLED 显示欢迎眨眼动画
3. **选择**: ↑/↓ 键切换（支持上下循环滚动），确认键进入
4. **返回**: 任何模式按 **\*** 键返回主菜单

### 模式 1: Piano Game（钢琴下落节奏游戏）

**玩法**:
- 进入后先选难度（1=Easy / 2=Normal / 3=Hard），影响判定窗口和下落速度
- 4 条轨道，音符从上往下掉落，**从进入游戏 3 秒倒计时后自动演奏整首歌**（不依赖按键）
- 玩家用 **1/2/3/4** 或 **C/A/B/D** 按对应轨道命中音符，提升准确率和 Combo

**音符类型**:
- **Tap（点击）**: 白色方块，到判定线时按一下
- **Hold（长按）**: 灰色长条，按住到合适时长松手

**判定**:
- **Perfect** ≤ 120ms → Combo +1
- **Good** ≤ 200ms → Combo +1
- **Bad** ≤ 280ms → Combo 清零
- **Miss** 超时/漏键 → Combo 清零

**曲目列表**（6 首）:
1. Twinkle Star（小星星）
2. Happy Birthday（生日快乐）
3. Little Star v2（一闪一闪 B 段）
4. Ode to Joy（欢乐颂）
5. Jingle Bells（铃儿响叮当）
6. Mary's Lamb（玛丽有只小羊羔）

**进阶操作**:
- **5/6 键**: 切换曲目
- **确认键**: 暂停/继续
- **组合键**: 按住 **1+2**（左两键）或 **3+4**（右两键）触发 OLED 全屏角色动画

**结算**: 全部音符结束后显示评级（S/A/B/C/D，≥95% 为 S）、ACC 准确率、最高 Combo、P/G/B/M 分项统计

---

### 模式 2: Plane Battle（飞机大战）

- **操作**: A/B/C/D 四方向移动（← → 可长按连续移动），9 或确认键射击
- **规则**:
  - 初始 3 条命，击毁敌机得分 = `10 × 当前等级`
  - 敌机穿过底线或撞击玩家 → 扣 1 命
  - 每约 10 秒升级：敌机加速、血量增加
- **游戏结束**: 生命归零后显示最终分数，按确认重新开始

---

### 模式 3: Minesweeper（扫雷）

- **操作**: 方向键移动光标，确认键翻开/标记旗标
- **规则**: 翻开所有非雷格子即胜利，踩雷失败
- **特性**: 空白格自动展开，数字提示周围雷数

---

### 模式 4~6: Snake / Tetris / 2048

- **Snake（贪吃蛇）**: 方向键控制，吃果实长身体，撞墙/自身失败
- **Tetris（俄罗斯方块）**: 方向键移动/旋转，消行计分
- **2048**: 方向键滑动合并，达成 2048 或无路可走结束

---

### 模式 7: Study Buddy（番茄工作法）

1. ↑/↓ 选择时长（25/30/45/60 分钟）
2. 确认开始，主屏显示大字号倒计时 + 进度条
3. 确认键暂停/继续，每 5 分钟 OLED 眨眼鼓励
4. 计时归零播放成功音效，显示 Session 时长

---

### 模式 8~10: 学习模块

#### Vocabulary（背单词）
- **翻卡片模式**: 显示单词，确认翻面看释义，选择"记得"或"不记得"
- **选择题模式**: 四选一，选对计分
- 内置词表约 50 词

#### Math Drill（数学速算）
- 随机生成加减乘除运算题（个位数）
- 键盘输入答案，实时判对错，计时计分

#### Memory（记忆翻牌）
- 4×4 卡牌配对游戏
- 翻开两张，配对成功消除，全部消除胜利

## 🎯 特色机制

### 游戏时长限制（防沉迷）
- 连续游戏 **10 分钟**自动弹出提醒"Time's up! Take a break, study!"
- 自动返回主菜单，学习模块不受限制

### OLED 动态表情系统
- **18 种表情**（`emoji_bitmaps.h`）: 待机眨眼、钢琴 Combo、飞机射击、学习完成等
- **全屏角色**（phanion / mydei 系列）: 钢琴模式按组合键触发
- **自动动画**: 待机循环眨眼、结算时交替显示

### Ghost Shell 隐藏彩蛋
- 主菜单输入 **Konami 码**（↑ ↑ ↓ ↓ ← → ← →）解锁
- 进入调试终端，显示系统信息、传感器数据、内存占用

## 🛠️ 开发与编译

### 环境配置

**工具链**:
- **PlatformIO** (推荐 VS Code + PlatformIO 插件)
- **Arduino Framework for ESP32** (已在 platformio.ini 自动配置)

**依赖库** (platformio.ini 自动安装):
```ini
lib_deps =
    olikraus/U8g2@^2.36.18          # OLED 驱动
    adafruit/Adafruit GFX Library   # 图形基类
    adafruit/Adafruit ILI9341       # LCD 驱动
```

### 编译与烧录

```bash
# 编译
pio run

# 烧录到开发板（自动检测 USB 端口）
pio run --target upload

# 串口监视器（波特率 115200）
pio device monitor
```

**⚠️ 常见问题**:
- **中文路径导致链接失败**: 项目路径中含中文会导致 ld.exe 无法写 .map 文件，已通过 `disable_map.py` 脚本修复（见 `platformio.ini` 的 `extra_scripts = post:disable_map.py`）
- **COM 口识别**: ESP32-S3 有两个 USB 口（Native USB + CH343 UART 桥），烧录用 CH343 口（Windows 设备管理器可见 VID 1A86:55D3）
- **BROWNOUT 复位**: 低压会导致白屏+蜂鸣器响，换用手机充电器（5V/1A+）供电

### Wokwi 仿真

1. 安装 **Wokwi VS Code 插件**
2. **必须先编译一次**（`pio run`）生成 `firmware.elf`
3. 按 F1 → "Wokwi: Start Simulator" 启动云端仿真
4. 仿真配置见 `diagram.json` 和 `wokwi.toml`

## 🎵 钢琴模块技术说明

### 设计演进

**初版设计**（已弃用）:
- 4 条轨道固定 4 个音高（例如小星星用 C4 E4 G4 C5）
- 音符只记录"轨道号"，到判定线时查表发声
- **问题**: 小星星真正旋律是 `1 1 5 5 6 6 5`（6 个不同音），4 个音根本弹不成完整曲子

**现版设计**（已实现）:
- **每个音符携带真实音高** (0=C4, 1=D4, 2=E4 ... 12=A5)
- 6 首歌按简谱重写，用正确的音高序列 + 节奏
- 音符发声时长按时值（四分音符 ≈360ms，二分 ≈760ms），听起来连贯
- **显示轨道**由音高自动映射（低音→左轨，高音→右轨），旋律起伏时方块左右错落
- **自动演奏**: 音符到达判定线自动发声，无论玩家是否按中，形成完整旋律

### 如何添加新曲目

编辑 `src/piano_game.cpp`:

1. 增加 `MAX_SONGS`
2. 定义 `NoteProto` 数组（音高索引见代码注释），例如:
   ```cpp
   // Do Re Mi: 1 2 3 1 | 3 4 5 -
   static const NoteProto PROGMEM song6[] = {
     {0*Q,0,0,QD},{1*Q,1,0,QD},{2*Q,2,0,QD},{3*Q,0,0,QD},
     {4*Q,2,0,QD},{5*Q,3,0,QD},{6*Q,4,0,HD},
     {0xFFFFFFFF,0,0,0}
   };
   ```
3. 注册到 `songData[]`, `songNames[]`, `songLengths[]`

## 🔬 技术亮点

1. **双屏异步驱动**: ILI9341 SPI + SSD1306 I2C 并行工作，帧缓冲渲染避免闪烁
2. **非阻塞音频**: PWM 音效用状态机实现，不用 `delay()` 卡住游戏帧率
3. **GFXcanvas16 帧缓冲**: 240×320×16bit ≈150KB，必须用 ESP32-S3 的 PSRAM（C51 单片机无法实现）
4. **中文字库**: 嵌入 wqy 宋体 GB2312 子集，支持 OLED 中文显示
5. **模块化架构**: 每个游戏独立 `.cpp`，主循环通过模式枚举调度
6. **真实音高旋律**: 钢琴模块不用固定 4 音，而是每音符带音高，能弹出可辨认的曲子
